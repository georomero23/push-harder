# Animaciones de ejercicios propios

Sube aquí el GIF, WebP o MP4 de cada ejercicio propio (GitHub → esta carpeta → **Add file → Upload files**).
Luego, en la app: **Catálogo → +** y escribe el nombre exacto del archivo (ej. `hip-thrust-maquina.mp4`).

- Nombres en minúsculas, sin espacios ni acentos: `remo-en-maquina-hammer.mp4`.
- Preferible **MP4 o WebP**: pesan 5–10 veces menos que un GIF.
- Tamaño recomendado: 600 px de ancho, menos de 1.5 MB.
- Después de subirlo, GitHub Pages tarda ~1 minuto en publicarlo.
- Este repositorio es público: no subas videos con datos de alumnos.
